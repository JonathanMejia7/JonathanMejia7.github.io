Build your weekly AI summary

Get the most important posts from your sources every week, with date and original link. Use the prompt in any chat, or install the skill so it arrives on its own.

  • Skill
Option 1The prompt Any chat, even free. You paste it each week. Option 2The skill Claude Code or Codex. It arrives on its own and remembers what you've read.

Tap an option to see how to use it.

Option 1 · The prompt

Paste it into ChatGPT, Gemini or Claude with web search turned on. It works in the free versions that include search. To avoid repeats, paste last week's summary at the end.

Prompt

Fill in the highlighted parts with your details before pasting it.

I want to catch up on what my sources published in the last 7 days. Use web search and open each post before summarizing it.

TODAY IS: [today's date, for example: November 3, 2026]
MY COUNTRY: [for example: Ecuador]
MY TOPIC: [for example: logistics for small businesses]
WHAT I WANT IT FOR: [for example: I work in operations at a distributor]
MY SOURCES (3 to 5, with their link):
- [Name and link of source 1]
- [Name and link of source 2]
- [Name and link of source 3]
If I didn't list any sources, suggest 5 to 8 on my topic, with their link and the date of their latest post (for YouTube channels, the date of the latest video if you can see it; if not, say so), and wait for me to choose before writing the summary. Mix formats: at least one news outlet or magazine, one blog or newsletter by an author, and not only YouTube channels. Prioritize sources from my country or region; if you suggest one from another country, say so. Don't suggest sources that haven't posted in more than three months or links that don't open.

RULES
1. Only what was published in the 7 days before the TODAY IS date, including that day. Check the original date of each piece: if it's an old post with a new date, leave it out. If you can't find the date of a piece, either in the listing or when you open it, don't include it and say so in the coverage table.
2. Each item includes the author, the date and the original link.
3. Summarize what the content says, not the title. If the title exaggerates, write a descriptive one and explain in one sentence what it actually shows.
4. Separate what the author claims from what has been verified. Sales, revenue or results figures are the author's, unless they have a verifiable source.
5. If the post comes from a company that sells what it recommends, say so: "Content from [company], which sells [product]".
6. If you couldn't open or read something (a video without a transcript, paid content or a page that requires signing in), say so and include only the title, date and link. If you could only read a video's description, you can summarize it, but clarify "based on the description; I didn't watch the video". Don't invent summaries.
7. If a source didn't publish anything that week, say so; don't fill in with old material.
8. Within each source, take only what relates to my topic and read at most 10 posts in total, starting with the most useful for what I want. Mention the rest in the coverage table.
9. If I paste last week's summary at the end, don't repeat what's already there.

RESPONSE FORMAT
Weekly summary · [topic] · [dates]

This week: one sentence with the most important news.

Group the items by topic (not by source). In each topic:
- Author, "Title", date. One- or two-sentence summary. Link.
- Possible use: one sentence on how it could help me, based on what I want it for. If there's no clear use, write "no clear application for now".

At the end, a coverage table with each source: whether its content was read, only the listing was seen, it couldn't be opened, or it didn't publish that week.

Option 2 · The skill

A skill is a set of instructions that Claude Code or Codex follows when you ask. This one remembers what it already summarized so it doesn't repeat it, reads your sources' feeds so nothing is missed, groups the news by topic and tells you how each item could help you. Its instructions are in Spanish, but it writes your summary in the language you choose.

Download the skill (ZIP) See the code on GitHub

How to install and use it

  1. Get your tool ready

    You need Claude Code (in the Claude desktop app, Code tab) or Codex, on a Mac or Windows computer.

  2. Download and unzip the skill

    You'll get a folder called resumen-semanal, with the skill's instructions and a small program that reads your sources' feeds.

  3. Install it

    The easy way: open Claude Code or Codex and type "Install the skill in my Downloads/resumen-semanal folder". To do it by hand, copy the whole folder into ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex).

  4. Set it up

    Type "Set up my weekly summary in English". It asks for your topic, what you want it for, your country and how you want to receive it: in the chat, as a file, in a document, in Google Drive or by email. If you don't have sources, it suggests some and you pick 3 to 5.

  5. Run a first test

    Type "Prepare my weekly summary". It takes a few minutes because it opens each post before summarizing it. Check the result and tell it what to adjust: more detail, fewer topics, another source.

  6. Schedule it

    In Claude: Code tab, Scheduled and New task. In the instructions, type "Use the resumen-semanal skill and prepare this week's summary", choose Weekly, the day and the time. In Codex, create a scheduled task in its Scheduled section with the same text.

Which one is for you?

The prompt, if you want to try it.

It works in any chat and there's nothing to install. But you paste it each week and it starts from scratch.

The skill, if you want it to become a habit.

It arrives when you choose, doesn't repeat what you've already read, and you can adjust it over time.

Before you schedule it

Your computer has to be on.

Scheduled tasks run while the app is open and the computer is awake. In Claude, if one is missed, it runs when you reopen the app.

Connect email or Drive first.

To receive it by email, in a document or in Drive, connect that tool in Claude or Codex. A scheduled task can't ask you for permissions while it runs.

Check the links.

AI can make mistakes. Each item includes its original link so you can confirm what matters before you use it.

Your data stays with you.

The settings, memory and reports are saved on your computer, in the resumen-semanal folder in your user folder.
